## 第三方评测怎么说？优点和真实缺点

代理服务商 frproxy 的评测提到，大多数软件根本没有代理设置项，浏览器有，Discord、游戏和记账工具都没有，Proxifier 在系统层把连接接管过去，应用本身不用改配置。这是它最核心的卖点。

评测里列出的优点包括：对任何软件生效，可以按应用、端口和目标地址写细粒度规则，实时日志可读性好，浏览器端不留痕迹。itechguides 的定价页标注它提供 31 天试用，没有免费版，付费版按设备一次性计费。

缺点也比较具体。同一时间只能激活一个配置文件，不能并行跑多套规则，需要同时管理多个代理环境的人会觉得不够用。UDP 和 QUIC 流量要额外留意，游戏和部分语音工具走这类协议，规则没写对就会出问题。只支持 Windows 和 macOS，没有 Linux 版。

frproxy 还提醒了一点：Proxifier 只负责把流量转到你配置的代理，不改变浏览器指纹，Canvas、User-Agent、字体都还是原来的。想用它做多账号防关联是找错了工具，那是指纹浏览器的事。
